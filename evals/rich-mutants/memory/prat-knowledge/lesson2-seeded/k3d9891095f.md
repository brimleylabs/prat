It defines `skip_py38` through `skip_py315` and `skip_pypy3` markers and stacks them on tests whose docstring-derived output differs between versions. `test_inspect_text` hardcodes an attribute count of 34 on 3.11+ and 33 before that. When a new Python version is added to CI or `.python-version`, add a matching `skip_pyNN` marker and stack it on the version-specific tests. The expected boxes also embed the module path `tests.test_inspect...`, so renaming or moving the file breaks them.
