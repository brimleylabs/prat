`Box.__init__` unpacks exactly 8 lines of 4 characters (top, head, head_row, mid, row, foot_row, foot, bottom), so a malformed string fails at import time. `Box.substitute` swaps boxes via `LEGACY_WINDOWS_SUBSTITUTIONS` when `options.legacy_windows` is set, and falls back to `ASCII` when `options.ascii_only` is set and the box is not ASCII. `PLAIN_HEADED_SUBSTITUTIONS` maps headed boxes to plain ones. A new box should be added to those maps where relevant and to the `BOXES` demo list under `__main__`.
