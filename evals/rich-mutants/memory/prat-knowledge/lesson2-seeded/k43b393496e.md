This protocol is shared across all four rich slices. New renderables should yield Segments or nested renderables and give min/max width through Measurement so that Table, Columns and Panel can size them. The documented extension hooks (__rich__, __rich_console__, __rich_measure__, __rich_repr__) are the supported customization points.
