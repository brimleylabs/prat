Each generated file starts with the header "Auto generated by tools/make_width_tables.py" and takes its data from the wcwidth project. The table is built from `WIDE_EASTASIAN` (width 2) and `ZERO_WIDTH` (width 0), sorted. The VS16 narrow-to-wide set is taken from the "9.0.0" entry only and is the same for every version.
