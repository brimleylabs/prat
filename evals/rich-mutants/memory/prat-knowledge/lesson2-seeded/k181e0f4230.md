docs/images holds two SVG screenshots that the Sphinx docs embed. They only have to stay in step with the box styles and export feature they depict. I read all of box.svg. For svg_export.svg I read the CSS, the gradient rectangles, and the first text rows, but not the long text rows from about line 488 to the end.
