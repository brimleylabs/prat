This part of the repository root holds packaging and tooling config plus the translated READMEs for Rich, a Python library for rich text, tables, progress bars, markdown, syntax highlighting and tracebacks in the terminal. `pyproject.toml` defines the `rich` 15.1.0 package: it needs Python >=3.10, builds with `uv_build`, and sets mypy strict, pytest and isort. `tox.ini` runs lint, docs and a py310–py315 test matrix. `asv.conf.json` and `asvhashfile` drive the benchmark history stored in `benchmarks/results`. `faq.yml` configures FAQtory, which builds FAQ.md from `questions/`. `make.bat` is a Sphinx helper. `README.md` is the English master, with nine translations alongside it, and `SECURITY.md` points vulnerability reports to Tidelift.
