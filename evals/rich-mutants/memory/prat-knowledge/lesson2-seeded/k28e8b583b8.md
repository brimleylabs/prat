This is the first of four slices of the `rich` package, which renders styled text, tables, panels and other renderables in the terminal. It holds the package entry point (`rich/__init__.py`, with `print`, `inspect`, `print_json`, and a lazily created global `Console`) and the `python -m rich` demo (`rich/__main__.py`). It also holds small renderables (`rich/align.py`, `rich/bar.py`, `rich/box.py`), the ANSI-to-`Text` decoder (`rich/ansi.py`), and the Windows legacy-console layer (`rich/_win32_console.py`, `rich/_windows.py`, `rich/_windows_renderer.py`). The rest is private helpers and data tables: emoji, spinners, palettes, ratio maths, word wrapping, loop helpers and export templates. The big consumer is `rich/console.py`, which is outside this slice. `rich/live.py`, `rich/layout.py`, `rich/color.py`, `rich/columns.py` and others import from here. Modules here depend in turn on `rich/segment.py`, `rich/style.py`, `rich/text.py`, `rich/measure.py`, `rich/cells.py` and `rich/console.py`, so circular imports are managed with lazy imports and `TYPE_CHECKING`.
