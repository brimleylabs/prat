CONTRIBUTING.md requires updating CHANGELOG.md briefly, in the existing format. New entries go under '## Unreleased' with ### Added/Changed/Fixed headings, usually with a PR or issue link. First-time contributors also add themselves to CONTRIBUTORS.md, which is sorted alphabetically by surname.
