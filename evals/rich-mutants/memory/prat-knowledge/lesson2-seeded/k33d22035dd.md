The PR template asks for the latest black with default args, updates to CHANGELOG.md and CONTRIBUTORS.md, tests for new code, and a link to an issue or discussion. It also has an 'AI?' checkbox. AI-generated PRs are accepted only if the maintainer has responded on an issue or discussion first. A typo-only PR needs at least one fix in the docs to earn a CONTRIBUTORS.md entry.
