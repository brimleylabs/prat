Most files here have a `__main__` block that can be run as `python -m rich.<module>`. Examples are `rich.progress`, `rich.spinner`, `rich.status`, `rich.prompt`, `rich.pretty`, `rich.panel`, `rich.rule`, `rich.segment`, `rich.scope`, `rich.palette` and `rich.progress_bar`. `python -m rich.syntax PATH` is a small CLI with `-l`, `-i`, `-r`, `-t`, `-x` and `--highlight-line` flags (`-` reads stdin). These blocks are marked `# pragma: no cover`, so automated tests do not exercise them.
