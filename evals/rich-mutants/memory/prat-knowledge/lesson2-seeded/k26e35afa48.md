Each file mirrors a module: test_panel.py tests rich/panel.py, test_ratio.py tests rich/_ratio.py, and so on. Several files cover private helpers directly: test_pick.py (`rich/_pick.py`), test_stack.py (`rich/_stack.py`), test_ratio.py (`rich/_ratio.py` and `_loop`), and test_unicode_data.py (`rich/_unicode_data`). test_unicode_data.py checks that `load()` picks the nearest lower Unicode version, falls back to the lowest version below the first one, and loads the latest (17.0.0) for invalid strings. So adding a Unicode data version means updating the expected versions there.
