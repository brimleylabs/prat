`benchmarks/results/benchmarks.json` keys each entry by `benchmarks.<Class>.<method>` and stores the source `code` plus a `version` hash. The stored code for several suites (for example `TextSuite`, `SyntaxWrappingSuite`) shows a Console without `width=`, so it already differs from the current `benchmarks.py`. That file is regenerated by asv, so don't edit it by hand.
