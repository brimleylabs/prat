`traverse` walks the object depth-first into `Node` objects and handles recursion (`...`), `max_length`, `max_string`, `max_depth`, `__rich_repr__`, attrs, dataclasses, namedtuples and the containers in `_BRACES`. `Node.render` expands lines only where `check_length` exceeds `max_width`, or everywhere with `expand_all`. Objects with a custom `__repr__` (non-default dataclass or namedtuple repr, or container subclasses that override `__repr__`) are printed via `repr()` instead of being expanded. A `hasattr` probe with a gibberish attribute name detects objects that claim every attribute, and `protocol.rich_cast` uses the same trick.
