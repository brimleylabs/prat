Many tests carry `skipif(sys.platform == "win32")`, covering terminal color detection, `screen()`, `Layout` render, `refresh_screen` and the BrokenPipe test. test_logging.py calls `logging.basicConfig` and `log.addHandler(...)` at import time and in tests, so handlers accumulate on the shared `rich` logger across tests. test_live.py's autorefresh test sleeps in real time and only checks that nothing crashes. test_console.py's `test_size_can_fall_back_to_std_descriptors` patches `rich.console.os.get_terminal_size` and `WINDOWS` and indexes a dict by `sys.__stdin__.fileno()`, which can fail when the std streams are replaced.
