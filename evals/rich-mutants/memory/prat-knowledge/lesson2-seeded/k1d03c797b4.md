Console.print turns objects into renderables using rich_cast and __rich__. It then calls each renderable's __rich_console__(console, options), which yields Segments or nested renderables, and measures width-aware ones with __rich_measure__. The resulting Segments, each a text plus a Style, are buffered and written out when the buffer depth returns to 0.
