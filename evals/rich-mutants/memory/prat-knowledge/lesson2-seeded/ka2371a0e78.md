Tests build `Console(file=io.StringIO(), width=..., legacy_windows=False, _environ={})`, or use `console.capture()`, `begin_capture()` or `record=True` with `export_text()`. They then compare against full literal strings, including ANSI escapes such as `\x1b[38;2;...m`. Pass `force_terminal=True` and an explicit `color_system` when escapes are expected. `_environ={}` keeps the host environment from changing the output.
