`DEFAULT_STYLES` maps dotted names such as `repr.*`, `logging.level.*`, `markdown.*`, `json.*`, `traceback.*`, `progress.*`, `layout.tree.*`, `live.ellipsis`, `log.*`, `rule.*`, `table.*` and `status.spinner` to `Style` objects. `RegexHighlighter` subclasses build style names as `base_style` plus the regex group name (for example `repr.` plus `ipv4`, or `json.` plus `key`). Adding a new highlight group, markdown element or logging level means adding a matching entry here. A missing name raises `MissingStyle` unless `get_style(..., default=...)` is used, as the markdown code does.
