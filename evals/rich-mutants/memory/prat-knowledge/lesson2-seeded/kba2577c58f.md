`load('auto')` reads the UNICODE_VERSION environment variable and defaults to 'latest'. A malformed version falls back to the latest. A version that is not an exact match picks the nearest lower one via `bisect_left`, clamped to the first version. Short versions like '5' or '1.2' are padded to three integers by `_parse_version`, which raises ValueError on non-numeric parts.
