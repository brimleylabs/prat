Every other `*_unicode_heavy` benchmark builds `Text(snippets.UNICODE_HEAVY_TEXT)`. `TextSuite.time_divide_unicode_heavy` calls `self.text.divide(...)`, where `self.text` comes from `snippets.MARKUP`. It therefore doesn't measure what its name says. Fixing it changes the benchmark's code and so its asv version hash, which breaks comparison with history.
