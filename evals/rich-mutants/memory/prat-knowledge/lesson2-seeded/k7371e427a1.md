asv only collects methods named `time_*` (or other asv prefixes). `SegmentSuite` defines `test_divide_complex`, and no `benchmarks.SegmentSuite.*` entry appears in `benchmarks/results/benchmarks.json`. Rename it to `time_divide_complex` if you want it measured.
