rich/__init__.py creates a global Console lazily, and reconfigure() swaps its __dict__ instead of rebinding it. Named styles are resolved through Theme/ThemeStack, starting from default_styles.py. Color parsing, Style and the unicode tables are cached with lru_cache. Progress keeps per-task state behind a thread lock.
