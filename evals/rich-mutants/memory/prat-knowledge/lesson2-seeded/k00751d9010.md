`markup.render` returns a `Text`. It uses `RE_TAGS`, where tags start with `[a-z#/@` and backslashes escape tags in pairs. Closing tags pop by normalized style name, and `@` tags become `Style(meta=...)` parsed with `literal_eval`. `MarkupError` is raised for unmatched tags. `Markdown` uses `markdown_it` (with strikethrough and table enabled) and maps token types to `MarkdownElement` subclasses through `Markdown.elements`. A parent element takes over rendering of its children through `on_child_close`. With `hyperlinks=False`, links become a `Link` element rendered as `text (url)`.
