The FAQ template emits `#{{ question.slug }}` anchors, and `suggest.md` links to `{{ faq_url }}#{{ question.slug }}`. If you change how one template builds the slug or anchor, change the other to match. Both templates use `{%- ... -%}` whitespace control to shape the Markdown output, so check how the trimming affects blank lines before you reformat them.
