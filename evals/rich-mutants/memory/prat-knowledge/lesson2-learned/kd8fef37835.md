Module-level helpers `track`, `wrap_file` and `open` each build the same columns plus a `Progress` and delegate to the `Progress` methods. The column classes are `ProgressColumn` subclasses, and `TaskProgressColumn` extends `TextColumn`. `Task` is a dataclass that should be treated as read-only outside `Progress`. `Progress.make_tasks_table` builds a `Table.grid` from `self.columns`, and plain `str` columns are formatted with `column.format(task=task)`. New column types must implement `render(task)`.
