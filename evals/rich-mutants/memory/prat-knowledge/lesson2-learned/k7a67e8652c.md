`Text.__rich_console__` calls `wrap`, then joins the lines with `\n` and calls `render`. `wrap` splits on newlines, expands tabs, uses `divide_line` for word-wrap offsets, justifies via `Lines.justify`, then truncates. `render` turns spans into segments with a sorted start/end event list and a style stack, and caches combined styles. Span order matters because later spans override earlier ones, which is why `stylize_before` inserts at index 0. `Span.__bool__` is false for empty spans.
