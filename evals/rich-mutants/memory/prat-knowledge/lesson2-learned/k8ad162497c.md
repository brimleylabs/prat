`benchmarks/results/benchmarks.json` keys each entry by `benchmarks.<Class>.<method>` and stores the source `code` plus a `version` hash. Renaming or editing a benchmark therefore changes its identity and hash. The file is regenerated by asv, so don't edit it by hand.
