A `markers` line under [tool.pytest] in pyproject.toml had no effect, so custom marks such as `regression` still raised an unknown-mark warning. Register custom markers under [pytest] in tests/pytest.ini, for example `markers =` followed by `regression: regression test for a fixed bug`. Then re-run the test gate and confirm the warning is gone.
