Most rich modules end with an `if __name__ == "__main__":` demo block, run with `python -m rich.<module>` (e.g. `rich.progress`, `rich.spinner`, `rich.status`, `rich.prompt`, `rich.pretty`, `rich.panel`, `rich.table`), and `python -m rich` runs the full demo. `python -m rich.syntax PATH` is a small CLI with `-l`, `-i`, `-r`, `-t`, `-x` and `--highlight-line` flags (`-` reads stdin). These blocks are marked `# pragma: no cover`, so they are excluded from coverage and automated tests do not exercise them.
