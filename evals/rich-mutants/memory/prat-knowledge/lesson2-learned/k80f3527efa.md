It writes `../rich/_unicode_data/_versions.py` and one `unicode<major>-<minor>-<patch>.py` per version from `wcwidth.list_versions()`. Paths are relative to the current directory, so run it from inside tools/. It needs `wcwidth` and `black` already installed because it shells out to `black` on each generated file; at medium autonomy an agent cannot pip install them, so check availability first.
