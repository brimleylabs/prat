`Theme(styles, inherit=True)` starts from a copy of `DEFAULT_STYLES` from `default_styles.py` and then overlays the given styles, parsing strings with `Style.parse`. `ThemeStack.push_theme` merges with the top of the stack when `inherit` is true. `pop_theme` refuses to pop the base theme and raises `ThemeStackError`. `ThemeStack.get` is rebound to the top dict on every push or pop, so callers must not hold on to an old `.get`. `traceback.py` builds a `Theme(..., inherit=False)` from a Pygments theme and applies it with `console.use_theme`. `themes.py` only exposes `DEFAULT = Theme(DEFAULT_STYLES)`.
