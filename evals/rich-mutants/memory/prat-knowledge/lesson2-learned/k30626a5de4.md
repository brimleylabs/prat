Renderables such as `Padding`, `Constrain`, `Columns` and `Layout` implement `__rich_console__(self, console, options)` and are rendered by `Console.render`. They can yield other renderables, which `Console.render` recurses into. Use `options.update_width`, `update_height` or `update_dimensions` for child options, because the options object is copied rather than mutated. Add `__rich_measure__` returning a `Measurement` when the width depends on content, as `padding.py` and `constrain.py` do.
