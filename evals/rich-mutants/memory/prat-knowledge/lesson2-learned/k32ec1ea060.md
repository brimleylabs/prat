CONTRIBUTING.md and the PR template require a brief CHANGELOG.md entry in the existing format under '## Unreleased', using ### Added/Changed/Fixed headings, usually with a PR or issue link. First-time contributors also add themselves to CONTRIBUTORS.md, sorted alphabetically by surname. PRs should include tests and an issue link, and AI-generated PRs must follow the explicit rules in AI_POLICY.md.
