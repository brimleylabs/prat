`VERSIONS` in `_versions.py` must stay an ordered (sorted) tuple, since `VERSION_ORDER` is built from it and `load()` uses `VERSIONS[-1]` as 'latest'. `load()` resolves to the nearest lower version, falls back to the lowest version for input below the range, and uses the latest on bad input. tests/test_unicode_data.py hardcodes '17.0.0' as the latest and '4.1.0' as the first-version fallback, so update those when the range changes; data module names contain hyphens and are loaded by dynamic import.
