`Style` uses `__slots__`, bit-flag attributes (`_attributes` and `_set_attributes`) and `lru_cache` on `parse`, `_add`, `normalize` and `get_html_style`. Several methods (`copy`, `without_color`, `update_link`, `from_color`) build instances through `__new__`, so any new slot or field must be set in every one of those paths, and in `__init__`. `Style.__eq__` and `__hash__` compare via `_hash_getter` over colour, bgcolor, attributes, link and meta. `Segment._split_cells` is cached, and `split_cells` has a fast path for single-cell text.
