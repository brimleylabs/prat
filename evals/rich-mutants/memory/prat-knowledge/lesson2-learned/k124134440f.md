The usual pattern is `Console(file=io.StringIO(), width=..., color_system="truecolor", legacy_windows=False, _environ={})` followed by `console.file.getvalue()`, or `console.capture()` / `begin_capture()` / `end_capture()`. Passing `_environ={}` and `force_terminal=True` isolates the test from the host terminal and its env vars. Expected values are literal strings containing `\x1b[...` sequences, usually preceded by a `print(repr(result))` so a failing output can be copied into the test.
