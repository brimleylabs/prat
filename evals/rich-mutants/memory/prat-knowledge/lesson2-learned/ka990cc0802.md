`assets/logo.txt` is a 10-line ASCII drawing, and `imgs/logo.svg` is a vector file of about 45 KB. The SVG is one large `<svg>` element with a gradient, an outline filter and long path data, and it is not meant to be edited by hand. The other files in `imgs/` are PNGs and GIFs used by `rich/logging.py`, `benchmarks/snippets.py` and some tests, but no file I read points to `logo.svg`.
