This module is the Sphinx build scaffolding for the Rich documentation, plus two appendix pages. `docs/Makefile` and `docs/make.bat` are the stock Sphinx "make mode" wrappers. They read from `docs/source` and write to `docs/build`. `docs/requirements.txt` pins the doc toolchain: alabaster, Sphinx, sphinx-rtd-theme and sphinx-copybutton. `docs/source/appendix/box.rst` documents the `rich.box` constants, and `docs/source/appendix/colors.rst` lists the standard 8-bit terminal colors. Both appendix pages describe output that Rich generates itself, so they are tied to the library code and to `docs/images`.
