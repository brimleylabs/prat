This slice of `rich/` holds the core rendering pipeline and its helpers. `rich/console.py` has `Console`, `ConsoleOptions`, `Group`, the capture, pager, screen and theme context managers, buffered output, and the HTML, SVG and text exporters. Around it are cell-width maths (`cells.py`), color parsing and downgrading (`color.py`, `color_triplet.py`), control codes (`control.py`), measurement (`measure.py`), padding, constrain, containers, layout, columns, live display (`live.py`, `live_render.py`, `file_proxy.py`), markup, markdown, highlighters, JSON, the logging handler, the Jupyter mixin, and the default style table (`default_styles.py`). The renderable protocol is `__rich_console__(console, options)` yielding `Segment`s or nested renderables, plus an optional `__rich_measure__`. Most classes mix in `JupyterMixin`. The module depends on part 1 and part 3 files (`segment`, `style`, `text`, `table`, `theme`, `syntax`, `traceback` and others) and on part 4 files such as `_log_render`, `_ratio` and `_unicode_data`. Many files end with an `if __name__ == "__main__":  # pragma: no cover` demo; running `python -m rich.<module>` is the manual check for it.
