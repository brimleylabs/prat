The two progress-in-Live demos differ. live_progress.py uses `Panel.fit` inside `Table.grid()`. fullscreen.py uses `Panel` with `expand=True` on a grid and `screen=True`. group.py builds a `Group` explicitly, while group2.py uses the `@group()` decorator. table.py renders a table once, while table_movie.py builds the same table step by step under `Live`. Keep each variant, because they exist to show the contrast.
