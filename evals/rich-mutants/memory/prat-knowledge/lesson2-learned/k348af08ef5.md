`box.svg` uses `clipPath` per line, `.terminal-<hash>-matrix` with `line-height: 24.4px` and `font-variant-east-asian: full-width`, and a `<text>` per run. `svg_export.svg` is an older format: no clipPaths, `<rect>` background blocks, `<tspan>` runs, and `font-variant: east-asian-width-values`. Regenerating one will not make it match the other. Each also has its own random class-prefix hash (2816723390 for box, 2501951896 for svg_export), so class names change on every export.
