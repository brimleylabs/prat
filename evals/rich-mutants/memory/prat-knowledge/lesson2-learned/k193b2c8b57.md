docs/source/reference holds the Sphinx API reference for the Rich library: 36 tiny reStructuredText stubs, each a title plus a `.. automodule::` directive for one `rich.*` module, so content comes from docstrings in the `rich/` package. Files are named after the module they document (e.g. `progress_bar.rst` for `rich/progress_bar.py`), except `init.rst`, which documents the top-level `rich` package via `.. automodule:: rich`. Many modules in `rich/` have no page here (which ones was not checked), and how the files are pulled into the toctree from the parent docs/source directory was not read.
