tests/ (part 1) is the pytest suite for rich's core rendering layer: Console, Text markup and ANSI decoding, colors and cells, Align, Padding, Columns, Layout, Live, logging, Markdown, the highlighters and `inspect`. Most tests build a `Console(file=io.StringIO(), ...)` and assert on the exact string written, including ANSI escape codes, so they are golden-output tests. The suite is a package (`tests/__init__.py`), so helper modules are imported relatively, for example `from .render import render` and `from ._card_render import expected`. `tests/conftest.py` strips color env vars for every test. `tests/test_progress.py` and `tests/test_syntax.py` (part 2) import from this module. This part covers the other `rich/*` modules listed above, with `rich/console.py` the most heavily exercised.
