The .github directory holds the Rich repository's GitHub configuration: CI workflows, issue and PR templates, Dependabot settings and funding metadata. The main CI workflow, pythonpackage.yml, runs on pull requests. It runs format-check, typecheck and pytest with coverage through `uv` and the Makefile. The other workflows handle CodeQL scanning, codespell, FAQ suggestions on new issues, a comment when an issue closes, and a README-change notification. The templates tell contributors that Rich is not accepting new features, and that bug fixes are welcome. Most workflows and templates refer to the `master` branch and to the upstream Textualize/rich repository, while this clone's current branch is `main`.
