Both files are machine-generated Rich terminal exports. They contain hundreds of per-glyph `<text>` or `<tspan>` elements with absolute `x`/`y`/`textLength` values and generated `terminal-<hash>-rN` CSS classes. `box.svg` has a `<!-- Generated with Rich -->` comment. Manual edits are fragile and the next export overwrites them.
