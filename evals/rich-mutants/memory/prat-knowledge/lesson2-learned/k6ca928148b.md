cells.py measures terminal cell width by binary-searching the CellTable ranges returned by rich/_unicode_data.load(). That function picks one of 21 Unicode versions and is cached. The table files are generated by tools/make_width_tables.py. cells.py and _unicode_data import each other circularly.
