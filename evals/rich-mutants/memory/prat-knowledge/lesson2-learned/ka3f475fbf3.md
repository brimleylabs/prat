rich/_unicode_data holds the per-Unicode-version terminal cell-width tables that rich/cells.py uses to measure text. `__init__.py` exposes `load(unicode_version='auto')`, which returns a `CellTable` for the requested version. `_versions.py` lists the 21 available versions, from 4.1.0 to 17.0.0. Each `unicodeX-Y-Z.py` file is generated by tools/make_width_tables.py from the wcwidth project and builds one `cell_table = CellTable(version, [(start, end, width), ...], frozenset([...]))`. The tables are sorted ranges with widths 0 or 2, and cells.py binary-searches them. The frozenset after the ranges holds the `narrow_to_wide` characters. tests/test_unicode_data.py covers loading and version selection. I read `__init__.py`, `_versions.py`, the 10.0.0, 17.0.0 and 4.1.0 data files (the first two in part), cells.py and the test file. I did not read the other 18 data files in full, so their layout is inferred from those three.
