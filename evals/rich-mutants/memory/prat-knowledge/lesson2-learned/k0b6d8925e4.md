It needs the third-party `emoji` package. It imports `EMOJI_ALIAS_UNICODE` from `emoji.unicode_codes`, which newer emoji releases may no longer provide. It lowercases the keys, strips the colons, and writes `EMOJI=<dict>` to `_emoji_codes.py` in the working directory. You must move that file into rich/ yourself. The script does not write to rich/ directly.
