It writes `../rich/_unicode_data/_versions.py` and one `unicode<major>-<minor>-<patch>.py` per version returned by `wcwidth.list_versions()`. The paths are relative to the current directory, so run it from inside tools/. It needs `wcwidth` and `black` installed, because it shells out to `black` on each generated file.
