Tests build `Console(file=io.StringIO(), width=..., legacy_windows=False, _environ={})`, or use `capture()`, `begin_capture()` or `record=True` with `export_text()`, then compare against full literal strings including ANSI escapes such as `\x1b[38;2;...m`. Pass `force_terminal=True` and an explicit `color_system` when escapes are expected; `_environ={}` and tests/conftest.py (which removes FORCE_COLOR and NO_COLOR) keep the host environment from changing output. The shared helper is tests/render.py, and any change to rendering output shows up as expected-string diffs across many test files (test_console.py, test_table.py, test_panel.py, test_rule.py, test_progress.py).
