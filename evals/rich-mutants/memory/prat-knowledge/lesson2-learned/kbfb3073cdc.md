Files in rich/_unicode_data (e.g. unicode17-0-0.py, unicode10-0-0.py, unicode4-1-0.py) start with the header 'Auto generated by tools/make_width_tables.py' and take their data from the wcwidth project. Fix widths by editing the generator and regenerating, otherwise the next run overwrites a hand edit. The table is built from `WIDE_EASTASIAN` (width 2) and `ZERO_WIDTH` (width 0), sorted; the VS16 narrow-to-wide set comes from the "9.0.0" entry only and is the same for every version.
