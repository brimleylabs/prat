This group has no code. It holds the FAQtory templates that generate Rich's FAQ and its automatic reply to new issues, the PRAT project config that tells agents how to test the repo, and the project logo in two forms. `.faq/` feeds the GitHub workflows, such as `.github/workflows/newissue.yml`. `.prat/project.toml` defines the single `test` gate that every PRAT card must pass.
