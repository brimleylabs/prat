`VERSIONS` in `_versions.py` is an ordered tuple, and `load()` uses `VERSIONS[-1]` as 'latest'. `VERSION_ORDER` is built from it and sorted. tests/test_unicode_data.py hardcodes '17.0.0' as the latest and the first-version fallback '4.1.0', so update those tests when the range changes.
