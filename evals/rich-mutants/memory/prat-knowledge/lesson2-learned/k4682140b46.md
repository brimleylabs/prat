The team requires a regression test for each bug fix, and fixes without one are not merged. The test should fail on the unfixed code and pass with the fix, and carry @pytest.mark.regression so the regression job picks it up. The export_svg clip-width fix in rich/console.py was accepted only after a reviewer asked for this test.
