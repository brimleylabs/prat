`asv run` benchmarks the master branch, and `asv run HEAD^!` benchmarks the latest commit on your branch. `asv run HASHFILE:asvhashfile` runs the tags listed in the root `asvhashfile`. `asv publish` writes HTML to `benchmarks/html`, and `asv preview` serves it locally. The config is the root `asv.conf.json`. The HTML is then copied into the separate `rich-benchmarks` repo, whose GitHub Action updates the dashboard.
