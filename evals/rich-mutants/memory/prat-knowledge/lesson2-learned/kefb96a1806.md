The examples/ directory holds 36 small standalone Python scripts and a README. Each one demonstrates a Rich feature: tables, progress bars, Live displays, Layout, tracebacks, logging, highlighters, export, trees, columns, and others. They are not a package and have no shared helpers. Each imports the public API from `rich` (for example `rich.console`, `rich.table`, `rich.progress`, `rich.live`) and is run directly with `python examples/<name>.py`. There are no tests here, so these scripts show the public API as the project intends it to be used. Several need a network, optional libraries, or arguments.
