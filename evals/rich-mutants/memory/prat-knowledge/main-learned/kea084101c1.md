`Theme(styles, inherit=True)` starts from a copy of `DEFAULT_STYLES` and parses string styles with `Style.parse`. `ThemeStack.push_theme` merges with the current top unless inherit is False, and `pop_theme` raises `ThemeStackError` on the base theme. The stack rebinds `self.get` on every push and pop. `themes.py` only exposes `DEFAULT = Theme(DEFAULT_STYLES)`.
