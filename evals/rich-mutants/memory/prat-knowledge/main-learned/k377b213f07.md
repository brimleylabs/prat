`Syntax.get_theme` returns `ANSISyntaxTheme` for the names `ansi_light` and `ansi_dark` (the `RICH_SYNTAX_THEMES` dict). Any other theme name goes to `PygmentsSyntaxTheme`, which falls back to the Pygments `default` style on `ClassNotFound`. The default theme is `monokai`. A plain render with no line numbers, wrapping or range takes a shortcut path in `_get_syntax`. The padded, line-numbered and wrapped paths are separate, so changes to rendering must be checked against both. `rich/syntax.py` requires `pygments` (declared `>=2.13.0,<3.0.0`).
