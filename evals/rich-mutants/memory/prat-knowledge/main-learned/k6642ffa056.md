pyproject.toml `[tool.mypy]` sets `files=["rich"]`, `strict=true` and enables `ignore-without-code`, `redundant-expr` and `truthy-bool`, so only the rich package is checked and it needs full type annotations (see also CONTRIBUTING.md). Every `# type: ignore` must carry an explicit error code. pygments, IPython and ipywidgets are the only modules with `ignore_missing_imports`; isort uses the black profile.
