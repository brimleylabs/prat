Each generated unicode*.py starts with the header '# Auto generated by tools/make_width_tables.py' and takes its data from the wcwidth project. The generator builds a rich.cells.CellTable(version, table, frozenset(narrow_to_wide)) for each version in wcwidth's list_versions(). If the CellTable signature in rich/cells.py changes, the generator and its output template must change with it.
