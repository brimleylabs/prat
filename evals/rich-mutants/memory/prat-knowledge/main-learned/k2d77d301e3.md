Python examples use `::` followed by 4-space-indented code, and REPL snippets use `>>>`. Sample output is usually a `.. raw:: html` block holding a `<pre>` with inline-styled <span> elements, not generated at build time. Examples are in console.rst, layout.rst, tables.rst and introduction.rst. If you change an example's behaviour, its HTML block does not update on its own and has to be edited by hand.
