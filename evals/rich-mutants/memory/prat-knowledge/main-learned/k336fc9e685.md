This module covers rich's content and presentation layer. `text.py` holds `Text`, a string plus style `Span`s, and `Span`. `table.py` and `tree.py` are renderables that use the Console protocol. `theme.py` and `themes.py` define style containers, and `terminal_theme.py` defines colour palettes for exporting. `traceback.py` renders exceptions with Syntax, Panel, Columns, pretty and scope. Console, Markdown, Pretty, Progress, the highlighters and others build on `Text`, `Table` and `Theme`, and these files import the lower-level helpers (`_loop`, `_ratio`, `_wrap`, `cells`, `measure`, `segment`, `style`). Renderables implement `__rich_console__` (yielding Segments) and `__rich_measure__` (returning a `Measurement`).
