`load("auto")` reads the `UNICODE_VERSION` environment variable and defaults to `"latest"`. An invalid value silently falls back to latest. A valid but unlisted version picks the nearest lower entry using `bisect_left` over `VERSION_ORDER`. A version below 4.1.0 gets 4.1.0, and one above 17.0.0 gets 17.0.0. `_parse_version` pads short versions with zeros, so `"5"` becomes `(5, 0, 0)`. Tests pin this behaviour.
