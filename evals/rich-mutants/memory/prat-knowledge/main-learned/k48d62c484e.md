`load` is wrapped in `functools.cache` and keyed on the `unicode_version` argument. `load("auto")` therefore reads `UNICODE_VERSION` only once per process, and later changes to the variable are ignored. Tests or code that need a different version should pass it explicitly, or clear the cache with `load.cache_clear()`. Only the chosen table module is imported, which keeps start-up cheap.
