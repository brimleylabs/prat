docs/source/conf.py sets `release = Distribution.from_name("rich").version`, which raises if the rich package is not installed in the build environment. It also imports sphinx_rtd_theme at module level. Install the project and the docs dependencies (Sphinx, sphinx-rtd-theme, sphinx-copybutton) before building.
