Tests that assert exact ANSI output build the Console explicitly: `file=io.StringIO()`, `force_terminal=True`, a fixed `width`, `color_system`, `legacy_windows=False`, and often `_environ={}`. Without these, the environment or platform changes the output. Alternatively use record/capture, then compare against literal snapshot strings; tests/render.py provides the shared render() and replace_link_ids() helpers. Copy this setup in new rendering tests (see tests/test_console.py, tests/test_table.py, tests/test_panel.py, tests/test_progress.py, tests/test_rule.py).
