`Box.__init__` unpacks `box.splitlines()` into 8 lines and each line into 4 characters, so a malformed row raises on import. `LEGACY_WINDOWS_SUBSTITUTIONS` and `PLAIN_HEADED_SUBSTITUTIONS` map Box objects to replacements, and `Box.substitute` falls back to `ASCII` when `options.ascii_only` is set and the box is not ascii. A new box that needs fallbacks has to be added to those maps and to the `BOXES` list in the `__main__` demo.
