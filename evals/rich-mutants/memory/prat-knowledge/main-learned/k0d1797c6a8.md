docs/images holds two generated Rich terminal screenshots saved as SVG. The Sphinx docs embed them: box.svg is used in docs/source/appendix/box.rst, and svg_export.svg is used in docs/source/console.rst. box.svg shows every box style constant (box.ASCII, box.DOUBLE, box.HEAVY, box.SQUARE and so on) as a small table with header, cell and footer rows. svg_export.svg is a Rich console export of colored text with a rainbow gradient. Neither file contains source logic. Both are output from Rich's own SVG export, so regenerate them with Rich rather than editing them.
