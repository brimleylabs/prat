Every table file starts with `# Auto generated by tools/make_width_tables.py` and `# Data from wcwidth project`. Fix data problems by changing the generator and regenerating, because manual edits to the tuples will be lost. The files are large (400-700 lines) and nearly identical, so a diff between neighbouring versions is the quickest way to see what changed.
