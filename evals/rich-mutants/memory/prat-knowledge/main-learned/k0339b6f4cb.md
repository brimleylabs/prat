`traverse()` tracks `visited_ids` to print `...` for cycles. It probes `hasattr(obj, 'awehoi234...')` to skip objects that claim every attribute. It wraps `repr()` in try/except and emits `<repr-error ...>`. Dataclasses and namedtuples are expanded only when they use the default repr (`_is_dataclass_repr`, `_has_default_namedtuple_repr`). `attrs` is an optional import, and `is_expandable` is the public gate. `protocol.rich_cast` uses a similar gibberish-attribute check and a visited-type set to stop `__rich__` loops.
