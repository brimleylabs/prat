This is the second half of rich's pytest suite, covering Panel, Pretty, Progress, Prompt, Repr, Rule, Segment, Spinner/Status, Style, Syntax, Table, Text, Theme, Traceback, Tree, the small `_pick`/`_ratio`/`_stack` helpers (there is no `_loop` test file), the `_unicode_data` loader, and the Windows legacy console. Most tests build a `Console` that writes to `io.StringIO` (or use `capture()`/`record=True`) and compare against exact output, including raw ANSI escape strings. A few import the shared `tests/render.py` helpers (`render`, `replace_link_ids`). The Windows tests (`test_win32_console.py`, `test_windows_renderer.py`) only run on win32 and mock the Win32 API calls.
