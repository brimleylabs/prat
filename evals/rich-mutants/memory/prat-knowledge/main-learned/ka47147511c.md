This slice of `rich/` holds the rendering core. `rich/console.py` defines `Console`, `ConsoleOptions`, `Group` and the render and export pipeline. Around it sit the pieces that pipeline needs: width measuring (`measure.py`, `cells.py`), colour (`color.py`, `color_triplet.py`), control codes (`control.py`), and the default theme (`default_styles.py`). It also contains layout and container renderables (`padding.py`, `constrain.py`, `columns.py`, `layout.py`, `containers.py`), and content renderables and highlighters (`markup.py`, `markdown.py`, `json.py`, `highlighter.py`, `emoji.py`). `live.py`, `live_render.py` and `file_proxy.py` handle live display, and `logging.py`, `jupyter.py`, `pager.py`, `errors.py`, `filesize.py` and `diagnose.py` cover integrations and utilities. Renderables follow one protocol: `__rich_console__(console, options)` yields `Segment`s or further renderables, and an optional `__rich_measure__` returns a `Measurement`. `Console.print`, `Console.log` and `Console.render_lines` drive that protocol, and many modules (`Panel`, `Table`, `Text`, `Syntax`, `Progress`) build on these types.
