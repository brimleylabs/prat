docs/source is the Sphinx source tree for Rich's hand-written user guide: one reStructuredText page per feature (Console, Style, Markup, Text, Tables, Progress, Live, Layout, Tree, Traceback, Prompt and so on), plus the protocol page. conf.py configures the build with the sphinx_rtd_theme theme, autodoc, napoleon, viewcode, intersphinx, autosectionlabel and sphinx_copybutton. index.rst holds the main toctree. reference.rst and appendix.rst pull in the sub-directories docs/source/reference/ and docs/source/appendix/, which are outside this module's file list. The guide pages link by :class:/:meth: roles to the API reference generated from the rich/ package, and they point to scripts in examples/. Several pages embed pre-rendered terminal output as raw HTML <pre> blocks.
