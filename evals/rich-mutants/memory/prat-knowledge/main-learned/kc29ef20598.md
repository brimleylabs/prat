`ratio_resolve` uses `Fraction` and carries the rounding remainder to the next edge. If minimum sizes cannot be met, its result may exceed `total`. `ratio_reduce` and `ratio_distribute` return integers that sum to `total`, and `ratio_distribute` asserts the ratios sum to more than 0. `_wrap.divide_line` measures width in terminal cells via `cells.cell_len` and `chop_cells`, not `len`, so wide characters stay correct.
