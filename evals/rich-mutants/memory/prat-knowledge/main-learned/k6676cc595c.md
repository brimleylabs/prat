render(renderable, no_wrap=False) uses a width-100 truecolor Console on StringIO and runs replace_link_ids, which rewrites the random `id=...;path` in OSC 8 links to `id=0;foo` so output is reproducible. test_bar, test_block_bar and test_emoji import it as `from .render import render`, which requires tests/__init__.py. Several test files (test_markdown, test_log, test_card, test_markdown_no_hyperlinks) define their own copy of the same helper.
