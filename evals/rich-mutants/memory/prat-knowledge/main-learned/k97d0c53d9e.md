Highlighters, Markdown, logging, Progress and Traceback look up styles by dotted names such as 'repr.number', 'bar.complete' or 'progress.percentage'. These names are defined in DEFAULT_STYLES in rich/default_styles.py. A new style name needs an entry there, or in a Theme passed to the Console.
