`rich/__init__.py` imports `Console` only under `TYPE_CHECKING` or inside functions (`get_console`, `reconfigure`, `print`). `_extension.py` imports `rich.pretty` and `rich.traceback` inside `load_ipython_extension` and says this prevents a circular import. Putting a top-level `from .console import ...` in these files would break `import rich`.
