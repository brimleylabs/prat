Targets: `make test` runs pytest with coverage on `tests/` with TERM=unknown; `make test-no-cov` skips coverage; `make typecheck` runs `uv run mypy -p rich --no-incremental`; `make format-check` and `make format` run black; `make docs` builds Sphinx from `docs/`. Setup is `uv sync` (CI runs `uv sync --locked`, against uv.lock). Without make, CONTRIBUTING.md gives the equivalent `uv run` commands.
