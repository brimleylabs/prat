`test_handler` in test_traceback.py matches frame lines with the regex `rich/tests/test_traceback.py:`, so it depends on the repo directory being named `rich`. `test_pretty.py` calls `install()`, which replaces `sys.displayhook`. `test_rich_print.py` mutates the global console from `rich.get_console()` and restores `console.file` in `finally` blocks. `test_pretty.py::test_install` and the `rich.reconfigure` call in test_rich_print.py change global state. Restore global state the same way if you add similar tests.
