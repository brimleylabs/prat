`markup.render` parses `[tag]` with `RE_TAGS` and turns an open/close stack into `Text` spans. Unmatched closing tags raise `MarkupError`, and `escape()` handles backslash-escaped tags. `Markdown` walks markdown-it tokens and dispatches through the `elements` class dict to `MarkdownElement` subclasses, so a new block type needs an entry there. `RichHandler` exposes `render_message`, `render`, `get_level_text`, `KEYWORDS` and `HIGHLIGHTER_CLASS` for subclassing. It keeps markup off by default, and a per-record `markup` or `highlighter` attribute overrides it.
