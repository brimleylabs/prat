This module holds the Sphinx build tooling and two appendix pages for the Rich documentation. `docs/Makefile` and `docs/make.bat` are the stock Sphinx wrappers: they build from `source` into `build`. `docs/requirements.txt` pins the doc toolchain (alabaster, Sphinx, sphinx-rtd-theme, sphinx-copybutton). `docs/source/appendix/box.rst` documents the `rich.box` constants and embeds `docs/images/box.svg`. `docs/source/appendix/colors.rst` is a static HTML table of the 8-bit standard colors. Both pages describe behavior that lives in the `rich` package, in `rich/box.py` and `rich/color.py`.
