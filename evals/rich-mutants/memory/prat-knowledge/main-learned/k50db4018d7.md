`Text._text` is a list of string fragments, and `plain` joins them on demand. Anything that edits `_text`, `_length` or `_spans` directly, such as append, join, expand_tabs, right_crop and truncate, has to keep `_length` and the span offsets consistent with the text. Spans are character indices, while widths use `cell_len`, so don't mix the two.
