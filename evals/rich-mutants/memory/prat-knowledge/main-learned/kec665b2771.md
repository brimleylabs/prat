`asv run` benchmarks the main branch, and `asv run HEAD^!` benchmarks only the latest commit. `asv publish` writes HTML to `benchmarks/html`, and `asv preview` serves it locally. To update the public dashboard, run `asv run HASHFILE:asvhashfile`, publish, then copy the HTML into the separate `rich-benchmarks` repo.
