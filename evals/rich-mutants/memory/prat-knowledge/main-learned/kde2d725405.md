Run `make html` on POSIX or `make.bat html` on Windows from `docs/`. Both wrappers call `sphinx-build -M <target> source build`. With no target they run `help`. Set `SPHINXBUILD`, `SPHINXOPTS` or `O` to override the build command or add options. Output goes to `docs/build`.
