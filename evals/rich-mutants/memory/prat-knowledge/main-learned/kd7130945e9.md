This part of the repo root holds Rich's packaging and tooling config plus its README set. pyproject.toml defines the `rich` 15.1.0 package: Python >=3.10, runtime deps markdown-it-py and pygments, a `jupyter` extra, and a uv_build backend. It also holds the mypy strict config and the pytest `testpaths`. tox.ini runs lint, docs and per-Python test envs. asv.conf.json and asvhashfile configure the airspeed-velocity benchmarks, which write to benchmarks/results. faq.yml configures FAQtory, which builds FAQ.md from questions/ and the .faq templates. make.bat is the Windows Sphinx wrapper for docs. README.md is the English source of truth, and ten translated READMEs (it, ja, kr, pl, pt-br, ru, sv, tr, zh-tw here) mirror it. All of them link to each other in a header language list and to images in imgs/.
