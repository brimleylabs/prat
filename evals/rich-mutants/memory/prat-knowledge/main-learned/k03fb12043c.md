docs/source/reference.rst lists every page as `reference/<name>.rst`. A new stub that isn't added there won't be linked into the docs, and Sphinx will warn that the document isn't in any toctree. The list is roughly alphabetical, but `progress_bar` comes before `progress` and `abc` is last, so don't assume it is sorted.
