`TextSuite.time_divide_unicode_heavy` calls `self.text.divide(...)`, which is the markup text from `setup`. It does not use `snippets.UNICODE_HEAVY_TEXT`, unlike the other `*_unicode_heavy` methods. Also, `time_align_center_unicode_heavy` sizes its width from `len(LOREM_IPSUM)`. Fix these before relying on those numbers.
