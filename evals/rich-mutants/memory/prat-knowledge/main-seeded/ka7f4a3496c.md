docs/source/reference holds 36 small reStructuredText stubs that make up the Sphinx API reference for Rich. Each stub is a title plus one `automodule` directive, so the content comes from docstrings in the matching `rich/*.py` module. The pages are listed in the toctree in docs/source/reference.rst. The `autodoc` extension and `autodoc_typehints = "description"` are set in docs/source/conf.py. Changing the API docs usually means editing docstrings in `rich/`. Edits here are limited to adding, removing or re-scoping a page.
