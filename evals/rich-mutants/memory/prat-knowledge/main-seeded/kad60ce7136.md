The README translations (for example `README.de.md` and `README.fr.md`) embed `https://github.com/textualize/rich/raw/main/imgs/logo.svg` on line 8. Renaming or moving the file would break the logo in all of them. The SVG is one huge line, so use Grep rather than Read on it, and avoid editing it by hand.
