The page is one `.. raw:: html` block holding a `<pre>` copy of a rendered Rich table, with inline `style=` spans and box-drawing characters. It does not update itself when the color data in `rich/color.py` changes. Regenerate the whole block from Rich's HTML output instead of editing rows by hand. The table has 8-bit colors only: rows 0-15 have blank Hex and RGB cells, and some numbers are skipped (for example 19 and 23), apparently because duplicate names are omitted.
