Console (rich/console.py) turns each object into a renderable using rich_cast and is_renderable from protocol.py. It calls __rich_console__(console, options), which yields Segments or more renderables. It also calls __rich_measure__ for widths, using measure.py and cells.py. Segments carry Style objects and collect in a thread-local buffer, and the buffer is written out when its depth returns to zero.
