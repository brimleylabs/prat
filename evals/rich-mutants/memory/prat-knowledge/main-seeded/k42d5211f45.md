RegexHighlighter subclasses set `base_style` ("example." or "req.") and name their regex groups. A matching `Theme` maps keys like `example.email` and `req.method`, and the theme is passed to `Console(theme=...)`. Strings use Rich markup such as `[b]`, `[link=...]` and `:emoji:`, and `rich.markup.escape` guards user-supplied names in examples/tree.py. See examples/highlighter.py and examples/log.py.
