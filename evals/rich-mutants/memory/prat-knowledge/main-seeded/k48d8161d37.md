It needs the third-party 'emoji' package and imports EMOJI_ALIAS_UNICODE from emoji.unicode_codes, which may not exist in newer emoji releases. It writes the file to the current working directory, not to rich/, so the output has to be moved by hand. Keys are lowercased with the colons stripped.
