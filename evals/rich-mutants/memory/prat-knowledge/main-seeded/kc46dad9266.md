Scripts such as examples/table.py, examples/log.py, examples/status.py and examples/dynamic_progress.py build and render output on import. Several never exit by themselves: examples/spinners.py and examples/top_lite_simulator.py loop forever, and examples/layout.py waits for Ctrl+C. Do not import them from tests or tooling, and expect them to hang if you run them unattended.
