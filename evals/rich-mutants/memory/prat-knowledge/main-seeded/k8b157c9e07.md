`Console.set_live` pushes a stack. A nested `Live` sets `_nested` and delegates to `_live_stack[0]`, which renders a `Group` of every live's renderable. `Live` registers itself as a `RenderHook`, which prepends cursor-reset controls and appends `LiveRender`, but only when `console.is_interactive`. `Live` wraps `sys.stdout` and `sys.stderr` in `FileProxy` only on a terminal or in Jupyter, and `Console.file` unwraps `rich_proxied_file` so the console does not write back into itself. `_RefreshThread` is a daemon thread that holds `live._lock` while refreshing. `stop()` sets `vertical_overflow='visible'` so the final frame renders in full.
