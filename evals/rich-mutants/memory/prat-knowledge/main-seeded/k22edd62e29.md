`make.bat` runs `%SPHINXBUILD%` once with output discarded and treats errorlevel 9009 as 'not found'. It does not quote the source and build paths. The Makefile quotes `"$(SOURCEDIR)"` and `"$(BUILDDIR)"`. If you change the directory variables in one wrapper, change the other too, and avoid paths containing spaces.
