Its CSS defines about 400 one-color classes (r1 to r399 and beyond) that create the rainbow gradient. Gradient characters each get their own class and text element, which makes the file large. Reading it all burns a lot of context, and diffs are noisy. Grep for specific classes or lines rather than reading it end to end.
