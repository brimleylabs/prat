`_win32_console.py` raises `ImportError` at import time unless `sys.platform == "win32"`, and it builds `ctypes` bindings at module level. `_windows.py` catches `AttributeError`, `ImportError` and `ValueError` and falls back to a `get_windows_console_features()` that returns all-False. Import these modules lazily or inside the same guard, never unconditionally.
