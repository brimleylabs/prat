`[tool.mypy]` sets `files=["rich"]`, `strict=true` and enables `ignore-without-code`, `redundant-expr` and `truthy-bool`. Every `# type: ignore` therefore needs an error code. pygments, IPython and ipywidgets are the only modules with `ignore_missing_imports`. isort uses the black profile.
