rich/__init__.py creates a global Console lazily, and reconfigure() swaps that Console's __dict__ in place. The Console holds a theme stack, the active Live and a thread-local render buffer. Style, cells and _unicode_data.load() use caches. Code that changes Style or cell width must keep those caches consistent.
