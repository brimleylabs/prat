Pages link to the API with :class:`~rich.x.Y`, :meth:`~rich.x.Y.z` and :func:. They link between pages with labels such as `.. _console_markup:`, `.. _styles:`, `.. _themes:`, `.. _live:`, `.. _progress:`, `.. _protocol:`, `.. _highlighting:` and `.. _interactive_mode:`, and with :ref:. autosectionlabel is enabled, so section titles can also be referenced, as in :ref:`Layout`, :ref:`Columns`, :ref:`Padding` and :ref:`Input`. Renaming or duplicating a heading or label can break these references.
