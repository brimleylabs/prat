Tests that compare escape codes build the Console explicitly: `file=io.StringIO()`, `force_terminal=True`, a fixed `width`, `color_system`, `legacy_windows=False`, and often `_environ={}`. Without these, the environment or the platform changes the output. Copy this setup in new rendering tests.
