`.faq/FAQ.md` loops over `questions` and emits a table of contents plus an anchored section for each question, using `question.title`, `question.slug` and `question.body`. It ends with a 'Generated by FAQtory' footer. Keep the `{%- ... %}` whitespace-control markers when editing, because they control the output spacing.
