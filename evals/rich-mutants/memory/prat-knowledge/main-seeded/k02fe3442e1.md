Cells are wrapped in `Padding` only if any padding is non-zero, and the cell's vertical alignment comes from `renderable.vertical` or the column. Header cells are forced to bottom alignment and footer cells to top. `Table.grid()` is a Table with no box, header, footer or edge, and `Table.add_row` accepts None for blank cells. It raises `errors.NotRenderableError` for objects that are not renderable.
