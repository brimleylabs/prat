`Console.print`, `log` and `control` run inside `with self:`, which calls `_enter_buffer` and `_exit_buffer`. The buffer is flushed only when `_buffer_index` returns to 0, in `_check_buffer` and `_write_buffer`. `capture()` and `pager()` rely on this by holding the buffer open, and `Live.stop` wraps its final refresh in `with self.console`. `_write_buffer` also handles recording, Jupyter display, the legacy Windows renderer, and splitting writes into chunks of at most 32 KiB // 4 characters on Windows. `quiet=True` discards the buffer.
