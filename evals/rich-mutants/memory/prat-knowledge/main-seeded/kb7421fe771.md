`tests/test_pretty.py` defines `skip_py38` through `skip_py315` markers. `test_attrs_broken_310` branches on `sys.version_info >= (3, 13)` because the AttributeError message differs, and its expected string contains the dotted test path (`tests.test_pretty...`). Traceback tests also skip by version: `last_instruction` is only populated on 3.11 and later, and notes need 3.11 or later. The project's Python range is 3.10 and later, so the older skip markers are inert.
