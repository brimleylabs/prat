cells.py measures character width with a CellTable that load_cell_table() picks by Unicode version. If the exact version is missing, it falls back to the nearest lower one. The table is cached and imported lazily. Width rules are: ranges are sorted, width is 0 or 2 inside ranges and 1 by default, and control segments count as zero width.
