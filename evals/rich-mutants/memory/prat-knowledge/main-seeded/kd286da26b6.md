tests/ (part 1) is the pytest suite for rich's console, rendering and text-utility modules (align, ansi, bar, box, cells, color, columns, console, highlighter, inspect, layout, live, log/logging, markdown, markup, padding and others). Most tests are snapshot-style. They build a Console that writes to io.StringIO with a fixed width and color system, print a renderable, and compare the output with a hard-coded escape-sequence string. tests/render.py and tests/_card_render.py are shared helpers that other tests import: test_bar, test_block_bar, test_emoji, test_card and test_syntax (in part 2) all use them. The tests import the public API from rich/, such as rich.console.Console, and a few private modules (rich._inspect, rich._null_file, rich._fileno, rich._palettes). Because expected strings are embedded, any change to rendering, wrapping, styles or theme output tends to break many tests at once.
