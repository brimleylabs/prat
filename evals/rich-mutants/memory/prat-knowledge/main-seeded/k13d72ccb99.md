`Segment.cell_length` returns 0 when the segment has control codes. `split_cells` has a fast path for single-cell text and otherwise calls the `lru_cache`d `_split_cells`, which replaces a double-width character cut in half with two spaces. The `split_lines`, `adjust_line_length`, `divide` and `simplify` classmethods all branch on `segment.control`. Changes to them need tests with wide characters and control segments.
