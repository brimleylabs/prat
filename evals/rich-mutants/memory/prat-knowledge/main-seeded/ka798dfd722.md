conftest.py removes FORCE_COLOR and NO_COLOR for every test, and the Makefile sets TERM=unknown. Console detection reads environment variables, which tests can override with _environ. The inspect, pretty and traceback tests are gated by Python version, and some tests are skipped on Windows or run only on win32.
