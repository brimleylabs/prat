Renderables look styles up by theme name (e.g. markdown.*, progress.*) through `console.get_style(name, default=...)`, which uses the theme stack (Theme/ThemeStack) and falls back to `Style.parse`. `DEFAULT_STYLES` in rich/default_styles.py holds all the dotted names, so when adding a renderable with a new `foo.bar` style name, add its default there. Traceback is the deliberate exception: it builds its own theme from a Pygments style, and exports use TerminalTheme palettes. `python -m rich.default_styles` prints the table (use `--html` for an HTML export).
