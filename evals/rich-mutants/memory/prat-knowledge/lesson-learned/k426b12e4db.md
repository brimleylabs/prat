Progress tests use a `MockClock` or a closure passed as `get_time=` with `auto_refresh=False`, so elapsed time and speed are deterministic. Spinner and Status tests pass `Console(get_time=...)`, and a step such as `time += 80/1000` advances the "dots" spinner by one frame. Prompt and `rich.print` tests (tests/test_prompt.py) inject streams or the global console instead. Write new tests for live or animated code the same way; only `test_track_thread` and `test_status` use `sleep`, so do not rely on real sleeps for output.
