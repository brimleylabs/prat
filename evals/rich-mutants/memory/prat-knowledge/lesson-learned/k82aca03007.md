This module holds Rich's higher-level renderables and styling pieces: `Table` (`rich/table.py`), `Text` and `Span` (`rich/text.py`), `Tree` (`rich/tree.py`), `Traceback` and `install` (`rich/traceback.py`), plus themes (`rich/theme.py`, `rich/themes.py`, `rich/terminal_theme.py`). `Text` is the base unit that nearly everything else renders through. It stores a string plus style `Span`s and renders to `Segment`s through the `__rich_console__` and `__rich_measure__` protocol. `Table`, `Tree` and `Traceback` follow the same protocol. They call `console.render_lines`, `Measurement.get`, `Padding`, `Panel`, `Syntax`, `Columns` and `Constrain`. `Theme` and `ThemeStack` map style names to `Style` objects, with defaults from `rich/default_styles.py`; `Console` uses them. `TerminalTheme` holds the colour palettes used when exporting to SVG or HTML.
