`Text._text` is a list that `plain` joins lazily, and `_length` is cached. Code that edits `_text` directly, such as `expand_tabs`, `truncate`, `right_crop` and `append`, must also update `_length` and trim or shift `_spans`. A new mutator that skips this leaves spans pointing past the end of the text.
