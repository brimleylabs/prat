`Column._cells` holds each column's cells, and `Table.rows` holds only `Row` metadata (style and `end_section`). `add_row` pads short rows with `None`, and adds a column if a row is longer than the existing columns. `_render` zips `_get_cells` for every column, so the header and footer are included as the first and last cells.
