The second `CellTable` field is a frozenset of single characters (`#`, `*`, digits, `©`, `®`, `™`, arrows and similar emoji-capable text symbols). `_cell_len` in `rich/cells.py` adds width 1 for these when they are followed by the VS16 selector `\ufe0f`. The old table `unicode4-1-0.py` also lists unassigned and noncharacter ranges such as `(131070, 131071, 0)` as width 0, and the 17.0.0 table does not, so old and new versions can differ in more than emoji.
