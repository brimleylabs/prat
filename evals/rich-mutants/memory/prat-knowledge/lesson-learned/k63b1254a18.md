`VERSIONS` in `_versions.py` is an ascending tuple of strings, and `load()` uses `VERSIONS[-1]` as 'latest'. A new data file only becomes reachable once it is appended there, in order. `tests/test_unicode_data.py` hard-codes "17.0.0" as the maximum and as the invalid-input fallback, so update those expectations too.
