`cells.py` has a fast path through `_is_single_cell_widths` over a fixed set of 1-cell character ranges. Other text goes through `get_character_cell_size` (binary search over the table from `rich/_unicode_data`) and grapheme handling for ZWJ (`\u200d`) and VS16 (`\ufe0f`). `cell_len` caches only strings under 512 characters. Splitting inside a double-width character substitutes spaces. Any layout or truncation code should use these helpers.
