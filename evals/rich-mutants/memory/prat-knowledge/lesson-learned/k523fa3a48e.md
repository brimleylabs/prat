This part of the `rich` package holds the public entry points and the low-level helpers the rest of the library builds on. `rich/__init__.py` provides lazily created global console helpers: `get_console`, `reconfigure`, `print`, `print_json` and `inspect`. `rich/__main__.py` builds the demo test card. Next to it are data tables (`_emoji_codes.py`, `_spinners.py`, `_palettes.py`, `_export_format.py`), box characters (`box.py`), and small layout and renderable helpers (`align.py`, `bar.py`, `_ratio.py`, `_wrap.py`, `_log_render.py`, `_inspect.py`, `_loop.py`, `_stack.py`, `_pick.py`). The Windows pieces (`_win32_console.py`, `_windows.py`, `_windows_renderer.py`) support terminals that lack ANSI processing. Most renderables follow the Rich protocol of `__rich_console__` plus `__rich_measure__` and subclass `JupyterMixin`. They import `Console`, `Segment`, `Style`, `Text` and `Table` from the other modules, and `console.py`, `live.py`, `layout.py`, `emoji.py`, `diagnose.py` and the examples import these modules in turn.
