Tests build a Console on StringIO with a fixed width and colour system and compare the exact output. A small change to console.py, segment.py, style.py or text.py can fail dozens of tests. `tests/_card_render.py` holds a single-line `expected` blob that `python tests/test_card.py` rewrites when run as `__main__` (the path is relative to the cwd), and test_bar, test_log, test_markdown and test_columns have a `__main__` block that prints the repr to paste back in. Update a golden string only after confirming the rendering change is intended.
