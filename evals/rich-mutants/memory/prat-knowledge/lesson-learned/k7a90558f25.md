`test_inspect.py` defines `skip_py38` through `skip_py315` and `skip_pypy3` markers, because docstrings and signatures of builtins render differently across versions, and the `str` attribute count depends on version. Several tests in `test_console.py` and `test_layout.py` skip on `win32`. `test_logging.py` skips its traceback test on `nt`. Expected strings embed the module path, for example `tests.test_inspect.Foo`, so test files must stay importable as part of the `tests` package.
