Each unicodeX-Y-Z.py file is produced from wcwidth tables as a `CellTable(version, widths, frozenset(narrow_to_wide))`, with widths as sorted (start, end, width) tuples (2 = wide East Asian, 0 = zero width). narrow_to_wide comes from wcwidth's VS16_NARROW_TO_WIDE for 9.0.0 and is identical in every version file. _versions.py (the VERSIONS list) is generated by the same script, but only the unicodeX-Y-Z.py files carry the 'Auto generated by tools/make_width_tables.py' header; __init__.py is hand-written.
