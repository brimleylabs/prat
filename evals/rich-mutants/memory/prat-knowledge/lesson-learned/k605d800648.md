`reconfigure()` builds a new `Console` and assigns its `__dict__` onto the existing global instance. Existing references to the global console therefore see the new settings, but it does not rebind `_console`. `rich.print(file=...)` creates a new `Console(file=file)` each call instead of using the global one. `rich.inspect` special-cases `inspect(inspect)` to turn on `help`, `methods` and `docs`.
