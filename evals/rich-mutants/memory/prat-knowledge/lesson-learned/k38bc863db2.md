The .github directory holds the GitHub configuration for the Rich terminal-formatting library. It contains the CI workflows (tests, CodeQL, codespell), issue and PR templates, Dependabot config, and a few maintainer automations. The templates state project policy: no new features, bug fixes welcome, and feature ideas go to discussions first. The CI test workflow drives the repo's Makefile targets and uv lockfile, so it ties directly to pyproject.toml, uv.lock and the rich/ and tests/ code. The FAQ-suggestion workflow ties to the FAQtory setup in .faq/.
