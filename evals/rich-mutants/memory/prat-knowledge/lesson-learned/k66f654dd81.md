This group holds the project's non-code support files for Rich, a Python library for rich text and formatting in the terminal. `.faq/` has two Jinja templates that FAQtory fills in. `FAQ.md` renders the FAQ page, and `suggest.md` renders the automatic reply on new issues. `.prat/project.toml` is the PRAT project config. It sets the test and lint commands and the verify gates. `assets/logo.txt` is an ASCII-art logo, and `imgs/logo.svg` is the vector logo, which has a gradient, an outline filter, and the Rich wordmark. None of these files contain executable code. They connect to the rest of the project through the FAQtory automation in `.github/workflows` and through the verify commands that run `tests/` and `tools/check_changelog.py`.
