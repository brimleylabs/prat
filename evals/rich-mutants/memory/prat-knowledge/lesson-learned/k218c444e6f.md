This is the middle slice of Rich's renderable library. It holds the low-level rendering primitives (`Segment`, `Style`/`StyleStack`, `Region`, `Screen`, `Styled`, `Palette`) and the protocol and repr helpers (`protocol.py`, `repr.py`). It also holds the higher-level renderables built on those primitives: `Panel`, `Rule`, `Pretty`/`pprint`, `Syntax`, `render_scope`, `Spinner`, `Status`, and the `Progress` stack (`progress.py`, `progress_bar.py`), plus the `Prompt` classes. Renderables follow the `__rich_console__`/`__rich_measure__` protocol. Their `__main__` blocks are demo scripts. The module depends on `console.py`, `text.py`, `table.py`, `live.py`, `measure.py`, `cells.py`, `color.py` and `box.py`, which are outside this slice. Many other files import it, including `rich/console.py`, `rich/text.py` and `rich/table.py`, so changes to `Segment` and `Style` affect nearly everything.
