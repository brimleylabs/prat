The benchmarks module holds Rich's performance benchmarks, which are run with Airspeed Velocity (`asv`) and configured in `asv.conf.json` at the repo root. `benchmarks/benchmarks.py` defines the suites: Text, Syntax wrapping, Table, Pretty, Style, Color, and Segment. Each suite builds a Console that writes to a StringIO, so rendering is measured without terminal output. `benchmarks/snippets.py` provides the shared input data: Python code, a dict, Lorem Ipsum, Japanese unicode-heavy text, and markup. `benchmarks/results/benchmarks.json` is asv's generated index of the benchmarks. The module imports the `rich` library (color, console, pretty, segment, style, syntax, table, text) and nothing imports it. The README describes how results are published to the separate `rich-benchmarks` dashboard repo.
