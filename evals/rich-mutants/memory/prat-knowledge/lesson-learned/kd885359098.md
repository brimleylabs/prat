`Theme(styles, inherit=True)` starts from a copy of `DEFAULT_STYLES`, and string styles are run through `Style.parse`. `ThemeStack` swaps its `get` attribute to the top dict's `.get` whenever the stack changes. `pop_theme` raises `ThemeStackError` if only the base theme is left. `rich/themes.py` only defines `DEFAULT = Theme(DEFAULT_STYLES)`.
