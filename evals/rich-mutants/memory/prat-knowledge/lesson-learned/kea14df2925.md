Each `*.question.md` file has YAML front matter (`title`, often `alt_titles`) followed by a short markdown answer. faq.yml points FAQtory at this directory (`questions_path: ./questions`), and the generated FAQ.md and issue-reply suggestions are built from these files with the templates in .faq/. The answers cover ANSI escapes, emoji, highlighting, Jupyter spacing, logging, square-bracket markup and tracebacks, and mostly link to rich.readthedocs.io. The directory has no code, so nothing runs against it.
