conf.py sets `release = Distribution.from_name("rich").version` and imports sphinx_rtd_theme at module level, so the build raises PackageNotFoundError or ImportError if `rich` (an editable install is enough) or the doc requirements (Sphinx, sphinx-rtd-theme, sphinx-copybutton) are missing. At medium autonomy agents cannot run pip install, so do not plan on a docs build unless those are already installed; check before relying on it.
