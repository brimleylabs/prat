spinners.py and top_lite_simulator.py loop forever with no exit handling. layout.py catches KeyboardInterrupt, so it can be stopped with Ctrl+C. fullscreen.py, layout.py, screen.py and top_lite_simulator.py use screen mode. export.py writes table_export_*.txt and .html files, and save_table_svg.py writes table.svg and opens it in a browser. Run these in a scratch directory and don't use them in automated checks without a timeout.
