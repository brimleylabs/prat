Tests build a Console on StringIO with a fixed width and colour system and compare the exact output. A small change to console.py, segment.py, style.py or text.py can fail dozens of tests in both halves of the suite. Only update expected strings when the new output is intended, and some goldens are regenerated by running the test file (for example tests/_card_render.py).
