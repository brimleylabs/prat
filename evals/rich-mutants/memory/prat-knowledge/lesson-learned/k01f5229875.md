attrs.py needs `attrs` and suppress.py needs `click`. Each wraps the import in try/except ImportError, prints a pip install hint and exits. These packages are not in the declared project dependencies, so keep that guard in any example that needs one. At medium autonomy `pip install` is denied, so do not try to install the package to run such an example; just confirm the guard path works if it is missing.
