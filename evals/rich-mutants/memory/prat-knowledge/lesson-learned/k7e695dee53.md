`tox` envlist is `lint`, `docs`, and `py310`–`py315`. Unit envs run `pytest --cov-report term-missing --cov=rich tests/ {posargs}`. `lint` runs `uv sync --locked`, then `make format-check` and `make typecheck`, deliberately calling make so local runs match the GitHub Actions pipelines. `docs` runs `sphinx-build -M html source build` from `docs/` with `docs/requirements.txt`.
