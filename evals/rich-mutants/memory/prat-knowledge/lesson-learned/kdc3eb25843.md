faq.yml sets `questions_path: ./questions`, `output_path: ./FAQ.md` and `templates_path: .faq`. Edit the question files and templates rather than FAQ.md itself. make.bat is the standard Sphinx wrapper for Windows (`SOURCEDIR=source`, `BUILDDIR=build`, `sphinx-build -M <target>`). It is meant to be run from `docs/`, since it uses relative `source` and `build` paths. SECURITY.md routes vulnerability reports to the Tidelift security contact.
