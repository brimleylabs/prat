conf.py loads sphinx.ext.autosectionlabel, which turns every section title into a label. Many pages reuse titles: 'Auto refresh', 'Print / log', 'Redirecting stdout / stderr', 'Alternate screen', 'Example(s)', 'Suppressing Frames', 'Columns' and 'Padding'. Refs such as :ref:`Columns` and :ref:`Padding` resolve through these auto-labels. Adding or renaming headings can therefore change which target a ref resolves to or trigger warnings, and conf.py does not set autosectionlabel_prefix_document.
