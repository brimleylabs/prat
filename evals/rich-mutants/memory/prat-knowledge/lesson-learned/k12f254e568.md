`Console.__enter__`/`__exit__` raise and lower `_buffer_index` in `ConsoleThreadLocals`, and output is only written to the file when the index returns to 0. `capture`, `pager`, `Live.refresh`, `FileProxy.write`, `control()` and `print()` all depend on this; Live and Progress install render hooks, push onto a live stack and redirect stdout/stderr through FileProxy, and Progress tasks may only be mutated under the lock. Bypassing the buffer, or changing `_write_buffer` and `_render_buffer`, affects recording, the Windows legacy renderer, Jupyter display and the 32KB split-write workaround on Windows.
