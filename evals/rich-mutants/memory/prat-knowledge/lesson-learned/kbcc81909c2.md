`Align` and `Bar` yield `Segment`s and use `Segment.line()` for line breaks. `Align` uses `Constrain`, `Segment.split_lines`, `get_shape` and `set_shape`, and `VerticalCenter` is deprecated in favour of `Align(vertical=...)`. `Bar` returns `Measurement(width, width)` for a fixed width and `Measurement(4, max_width)` otherwise. `Inspect` (in `_inspect.py`) returns a `Panel` from `__rich__`, and its styles are named `inspect.*` and `scope.border`, so they need entries in the theme. Most files end with an `if __name__ == '__main__':` demo block, marked `# pragma: no cover` in many of them.
