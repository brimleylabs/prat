Rendering tests create `Console(file=io.StringIO(), width=..., force_terminal=True, color_system=..., legacy_windows=False, _environ={})`. They compare `console.file.getvalue()` or `console.capture()` output with literal strings, and many `expected` values are raw ANSI escapes. Pin width, color_system, legacy_windows and `_environ` in new tests so results do not depend on the host terminal or environment variables.
