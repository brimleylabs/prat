`benchmarks/results/benchmarks.json` keys each entry by `benchmarks.<Class>.<method>`. It stores each method's source code, plus a `version` hash of that code and the setup. Changing a benchmark's code or setup gives it a new version, so asv treats earlier results as a different benchmark. Renaming a class or method starts a new series.
