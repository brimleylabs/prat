`make test` runs `TERM=unknown uv run pytest --cov-report term-missing --cov=rich tests/ -vv`. `make typecheck` runs `uv run mypy -p rich --no-incremental`. `make format-check` and `make format` run black, and `make docs` builds the docs with `cd docs; make html`. Setup is `uv sync`. CONTRIBUTING.md gives the same commands for people without make.
