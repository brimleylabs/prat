`get_character_cell_size` in `rich/cells.py` binary-searches `widths` and compares against `table[-1][1]` to decide that codepoints beyond the last range have width 1. Ranges therefore have to be sorted by start, and the last entry's end bounds the lookup. Entries use width 0 (combining marks, format characters, the tag block 917504–921599) or 2 (wide CJK and emoji). Width-1 characters are not listed, and codepoints outside every range return 1.
