`Box.__init__` unpacks exactly 8 lines (top, head, head_row, mid, row, foot_row, foot, bottom) of 4 characters each. A new box must keep that shape and set `ascii=True` if it uses ASCII only. `Box.substitute` uses `LEGACY_WINDOWS_SUBSTITUTIONS` when `options.legacy_windows` and `safe` are set, and falls back to `ASCII` when `options.ascii_only`. `PLAIN_HEADED_SUBSTITUTIONS` drives `get_plain_headed_box`. A new box also needs adding to the `BOXES` list in the `__main__` demo and to the substitution dicts where relevant.
