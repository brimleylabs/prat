columns.py fetches from randomuser.me, file_progress.py opens https://www.textualize.io and reads its Content-Length header, and downloader.py downloads URLs given on the command line (it breaks if a response has no Content-length). Network access is denied at medium autonomy, so verify these by reading the code or running only offline examples. cp_progress.py, listdir.py and tree.py need path arguments, and print_calendar.py's argparse requires a year.
