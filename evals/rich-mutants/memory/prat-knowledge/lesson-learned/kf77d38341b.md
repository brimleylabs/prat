`rich/cells.py` imports `load` from `rich._unicode_data` at the top. Each data module imports `CellTable` from `rich.cells`, but only when `load()` runs and imports it. `__init__.py` imports `CellTable` only under `TYPE_CHECKING`. Keep that structure: a top-level runtime import of `rich.cells` in `__init__.py` or `_versions.py` would create an import cycle.
