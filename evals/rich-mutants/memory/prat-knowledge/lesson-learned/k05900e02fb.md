Every text run has an absolute x/y position and a `textLength`, and colours and styles go through generated classes (`terminal-2816723390-r1..r5` in box.svg, a much longer r-series in svg_export.svg). Editing a string or colour by hand misaligns the layout or the class mapping. docs/source/appendix/box.rst documents `python -m rich.box` as the command that produces the box table shown in box.svg. No generating script for svg_export.svg was found.
