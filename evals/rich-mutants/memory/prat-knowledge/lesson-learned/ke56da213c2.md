box.rst defines `appendix_box` (underscore) and colors.rst defines `appendix-colors` (hyphen); both are referenced from panel.rst, tables.rst, console.rst and style.rst. The docs also use autosectionlabel (docs/source/conf.py), so repeated section titles produce duplicate-label warnings. Before renaming a heading or normalising a label, grep for it and update every `:ref:` use together, then check cross-references.
