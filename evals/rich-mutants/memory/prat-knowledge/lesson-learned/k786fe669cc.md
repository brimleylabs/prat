The PR template (.github/pull_request_template.md) asks for black with default args, mypy passing, tests for new code, updates to CHANGELOG.md and CONTRIBUTORS.md where appropriate, and a link to an issue or discussion; pre-commit hooks (.pre-commit-config.yaml) enforce part of this, and CONTRIBUTING.md repeats the requirements. A typo-only PR needs at least one fix in the docs to warrant a CONTRIBUTORS.md entry. AI-generated PRs must be disclosed and are accepted only if the maintainer has responded on an issue or discussion.
