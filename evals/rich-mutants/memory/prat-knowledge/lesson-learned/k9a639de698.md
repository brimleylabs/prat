It calls `logging.basicConfig` and adds a RichHandler to the shared `rich` logger. Some tests add handlers with `log.addHandler` and never remove them. Test order and handler accumulation can therefore matter, and new tests there should clean up handlers. Only `test_stderr_and_stdout_are_none` does.
