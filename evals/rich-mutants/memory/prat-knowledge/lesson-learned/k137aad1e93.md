PRAT's verify gates are the project's test command (`python -m pytest -q -p no:cacheprovider tests`) and lint command (`python tools/check_changelog.py`); use these rather than `make test`, which needs uv. The Makefile still defines `test`, `test-no-cov`, `format-check`, `format`, `typecheck` (`uv run mypy -p rich --no-incremental`) and `docs` (`cd docs; make html`), and CONTRIBUTING.md documents `uv sync` for setup. Do not run `uv sync` or any other install step at medium autonomy, because installs are denied.
