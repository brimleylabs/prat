`Console.is_terminal` checks `force_terminal`, then IDLE, then Jupyter, `TTY_COMPATIBLE`, `FORCE_COLOR`, and finally `isatty`. `is_interactive` honours `TTY_INTERACTIVE`. `no_color` comes from `NO_COLOR`. `_detect_color_system` uses `COLORTERM`, then the `TERM` suffix (`256color`, `kitty` and `16color` map to `_TERM_COLORS`), and uses the Windows console features on win32. Width and height come from `COLUMNS` and `LINES`, and Jupyter uses `JUPYTER_COLUMNS` and `JUPYTER_LINES` with defaults of 115 and 100. The `_environ` constructor argument exists so tests can inject an environment.
