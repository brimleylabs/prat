The PR template asks for black with default args, updates to CHANGELOG.md and CONTRIBUTORS.md where appropriate, tests for new code, and a link to an issue or discussion. A typo-only PR needs at least one fix in the docs to warrant a CONTRIBUTORS.md entry. AI-generated PRs must be disclosed and are accepted only if the maintainer has responded on an issue or discussion.
