`python tools/check_changelog.py [BASE_CHANGELOG]` exits 1 if rich/ changed but CHANGELOG.md has no new `- ` entry under `## Unreleased`. Without an argument it diffs against the git merge-base with main, and it counts uncommitted changes under rich/. With an argument it always assumes code changed and compares against that base file.
