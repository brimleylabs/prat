`load("auto")`, the default, reads `os.environ['UNICODE_VERSION']` and defaults to "latest". An invalid value is silently replaced by "latest". `load` is wrapped in `functools.cache`, so the environment variable is read once per distinct argument and changes made later in the process have no effect.
