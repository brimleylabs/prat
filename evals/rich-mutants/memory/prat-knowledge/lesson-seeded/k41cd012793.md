`_win32_console.py` raises `ImportError` at import time unless `sys.platform == 'win32'`. `_windows.py` wraps that import in `try/except (AttributeError, ImportError, ValueError)` and falls back to an all-False `WindowsConsoleFeatures`. `_windows_renderer.py` imports `_win32_console` directly, so only import it behind a Windows or legacy-Windows check. `WindowsCoordinates` is (row, col) while the Win32 `COORD` is (x, y), and `legacy_windows_render` converts the 1-based ANSI coordinates to 0-based.
