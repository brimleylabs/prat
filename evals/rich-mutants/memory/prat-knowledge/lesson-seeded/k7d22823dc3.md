columns.py fetches from randomuser.me, file_progress.py opens a URL (textualize.io) and reads its Content-Length header, and downloader.py downloads URLs given on the command line. downloader.py will break if a response has no Content-length. cp_progress.py, listdir.py and tree.py need path arguments, and print_calendar.py's argparse requires a year. Without arguments they print a usage message (print_calendar.py exits with an argparse error). Expect failures offline.
