`TextSuite.time_divide_unicode_heavy` calls `self.text.divide(...)`, where `self.text` is the markup text from setup. It does not use `snippets.UNICODE_HEAVY_TEXT` like its sibling `*_unicode_heavy` benchmarks. It therefore does not measure what its name says, and it can mutate the shared `self.text` instance.
