docs/source is the Sphinx source tree for Rich's user guide (the hand-written narrative pages). Each .rst page covers one feature (Console, Style, Markup, Text, Table, Progress, Live, Layout, Traceback, the console protocol, etc.) with short code samples. Pages link to the API reference through Sphinx roles such as :class:`~rich.table.Table`. index.rst holds the master toctree, and reference.rst and appendix.rst pull in sub-pages under docs/source/reference/ and docs/source/appendix/ (those were not in this module's file list). conf.py sets up the build: sphinx_rtd_theme, autodoc, napoleon, intersphinx, autosectionlabel and copybutton, and the release string is read from the installed `rich` distribution.
