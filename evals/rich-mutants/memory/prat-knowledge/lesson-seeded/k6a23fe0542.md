It writes ../rich/_unicode_data/_versions.py and ../rich/_unicode_data/unicodeX-Y-Z.py relative to the current directory. It needs the third-party `wcwidth` package and `black` on PATH, because it runs `black` via shell on each generated file. Running it from another directory writes to the wrong place or fails.
