`tests/_card_render.py` is a single-line `expected` blob that `test_card.py` compares with `make_test_card()` output. Running `python tests/test_card.py` as `__main__` rewrites it (the write path is `_card_render.py` relative to the cwd). Several other files (test_bar, test_log, test_markdown, test_columns) have a `__main__` block that prints the repr to paste back in. Change a golden string only after confirming the rendering change is intended.
