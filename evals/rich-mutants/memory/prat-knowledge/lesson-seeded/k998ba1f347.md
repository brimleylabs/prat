mypy runs with `strict = true` on `files = ["rich"]`. It also enables `ignore-without-code`, `redundant-expr` and `truthy-bool`, so every `# type: ignore` needs an error code. Pygments, IPython and ipywidgets are exempt via `ignore_missing_imports`. The package ships typed (`Typing :: Typed`). black >=26 and isort (profile black) are the formatters.
