`Traceback.__init__` takes `locals_overlow`, while `install` and `from_exception` take `locals_overflow` and pass it through as `locals_overlow=`. `extract` hides locals and handles exception groups only on Python 3.11 and later, and it reads `co_positions` to underline the failing instruction. The `max_frames` handling elides the middle frames and clamps the value to at least 4.
