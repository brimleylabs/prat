Run `make html` (or `make.bat html` on Windows) in docs/. Any target is passed to `sphinx-build -M <target> source build`, and plain `make` shows Sphinx help. `SPHINXBUILD` and `SPHINXOPTS`/`O` can be overridden, for example `make html O=-W` to fail on warnings. Install the dependencies first with `pip install -r docs/requirements.txt`.
