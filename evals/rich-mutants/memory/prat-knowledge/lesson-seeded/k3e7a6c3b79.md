dynamic_progress.py puts several Progress objects in a Group inside one Live. It hides finished tasks with `update(visible=False)`. jobs.py uses `Progress(auto_refresh=False)` with `progress.log` and `progress.track(task_id=...)`. live_progress.py and fullscreen.py show an overall bar and a per-job bar in a Table.grid, and fullscreen.py also puts it in a Layout. downloader.py uses a thread pool, a SIGINT handler that sets an Event, and `progress.console.log`. Copy these patterns when adding a progress demo.
