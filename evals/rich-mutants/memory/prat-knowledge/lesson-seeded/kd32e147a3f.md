`Live.start` calls `console.set_live`. A nested Live (not first in the stack) only sets `_nested`, and the first Live renders the whole stack as a `Group`. `process_renderables` prepends cursor-reset controls and appends `LiveRender`. `FileProxy` is installed over `sys.stdout` and `sys.stderr` only when the console is a terminal or Jupyter. `Console.file` unwraps `rich_proxied_file` to avoid recursion, and `LiveRender` tracks `_shape` to position the cursor, so changes there can corrupt terminal output.
