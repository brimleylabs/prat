Each suite is a plain class with `setup()` and `time_*` methods. Consoles are created as `Console(file=StringIO(), color_system="truecolor", legacy_windows=False, ...)` so output is deterministic and discarded. Shared inputs come from `from benchmarks import snippets`, which relies on `benchmarks/__init__.py` (an empty file) making the directory a package.
