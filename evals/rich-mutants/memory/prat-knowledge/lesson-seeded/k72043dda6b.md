`Console.render` calls `rich_cast`, then `__rich_console__`, and recursively renders any non-Segment output with `options.reset_height()`. Strings are turned into `Text` via `render_str`. `Measurement.get` falls back to `(0, max_width)` when no `__rich_measure__` exists. New renderables should subclass `JupyterMixin` (see `padding.py`, `constrain.py`, `columns.py`) so they display in notebooks.
