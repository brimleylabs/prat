docs/images holds two static SVG screenshots that the Sphinx docs embed. Rich generated both with its own SVG exporter, and nothing in the repo reads them as code. box.svg is the gallery of every built-in `rich.box` style: ASCII, DOUBLE, HEAVY, MINIMAL, ROUNDED, SQUARE and so on. Each style is drawn as a header and footer table in a four-column grid. `docs/source/appendix/box.rst` includes it with `.. image:: ../../images/box.svg`. svg_export.svg is the 'Rich features' demo screen: colour gradients, styles, text justification, Asian text, markup, tables, syntax highlighting, Markdown. `docs/source/console.rst` includes it with `.. image:: ../images/svg_export.svg`, where it illustrates `Console.export_svg`. The two files come from different Rich versions and differ in structure. Neither contains secrets or tooling.
