New entries go under `## Unreleased`, in `### Added`, `### Changed` or `### Fixed` subsections, usually ending with a link to the PR or issue. Released versions are written `## [x.y.z] - date`. Each release also has a compare-link line in the footer block at the bottom of the file. First-time contributors also add themselves to CONTRIBUTORS.md, which is sorted by surname with a GitHub link.
