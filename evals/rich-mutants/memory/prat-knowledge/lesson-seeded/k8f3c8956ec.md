`LogRender.__call__` returns a `Table.grid` with time, level, message and path columns. Repeated identical timestamps become blank padding when `omit_repeated_times` is set, and path links use `link file://...`. The `log.time`, `log.level`, `log.message` and `log.path` styles are part of the theme. `AnsiDecoder` in `ansi.py` ignores invalid SGR codes, keeps its `style` state across lines, and honours `\r` by keeping only text after the last one. `NullFile` returns `-1` from `fileno()` and `False` from `isatty()`, and `get_fileno` swallows any exception from `fileno()`.
