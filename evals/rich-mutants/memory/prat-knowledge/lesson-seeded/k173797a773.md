This is the first half of Rich's pytest suite. It covers the foundational modules: cells, color, console, markup, text containers, highlighters, live display, logging, markdown, inspect, layout, and the bar widgets. Most tests build a `Console` with a `StringIO` file and a fixed width. They then compare the exact output, ANSI escape codes included, against a literal expected string. `tests/render.py` and `tests/test_card.py` hold the shared render helpers. `tests/conftest.py` clears color-related environment variables for every test. Later test files (`tests/test_progress.py`, `tests/test_syntax.py`) import helpers from this module.
