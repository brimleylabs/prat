`Tree.make_guide` picks the guide set from the guide style: bold selects the heavy set and `underline2` selects the double-line set. It falls back to the thin set when `legacy_windows` is true, and uses `ASCII_GUIDES` when `ascii_only` is true. The measure code assumes 4 cells of indent per level, so `TREE_GUIDES` and `ASCII_GUIDES` entries must stay 4 cells wide. Each label's render width is reduced by the width of its prefix.
