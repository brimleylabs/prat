Progress tests use a `MockClock` or a closure passed as `get_time=`, with `auto_refresh=False`, so elapsed time and speed are deterministic. Spinner and Status tests pass `Console(get_time=...)`. A frame check such as `time += 80/1000` advances the "dots" spinner by one frame. Do not rely on real sleeps for output; only `test_track_thread` and `test_status` use `sleep`.
