The file is a `.. raw:: html` block of about 200 lines holding a `<pre>` table of the 256 standard colors. It uses inline spans with background-color and color styles, and the lines are indented to sit inside the directive. Edits by hand are easy to get wrong, because the indentation, the column alignment and the box-drawing characters all matter. Regenerate the block from Rich's own HTML export and paste it in instead.
