conf.py sets `release = Distribution.from_name("rich").version`. Without an installed `rich` distribution (for example an editable install of this repo), it raises PackageNotFoundError and the build fails. It also imports sphinx_rtd_theme at module level, so the doc requirements (Sphinx, sphinx-rtd-theme, sphinx-copybutton) must be installed too. autodoc imports the rich package to document it.
