rich.print and the other global helpers in rich/__init__.py create a global Console lazily. Console.render calls each renderable's __rich_console__(console, options), which yields Segment objects or nested renderables, and flattens them. Segments go into the console's thread-local buffer and are written out on _check_buffer, or are exported to HTML/SVG/text.
