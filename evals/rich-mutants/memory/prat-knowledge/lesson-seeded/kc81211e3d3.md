`Progress` and every `Task` share one `RLock`. `update`, `advance`, `reset` and `start_task` all take it, and `Task.speed` also takes it. `Progress.live` drives refresh, and `track()` runs a daemon `_TrackThread` when auto_refresh is on. `ProgressColumn.__call__` caches renderables per task id if `max_refresh` is set (for example `TimeRemainingColumn`, 0.5 s). `add_task` defaults to `total=100`, and `total=None` means a pulsing bar. The module-level `track`, `open` and `wrap_file` each rebuild the same default columns.
