`Console.__enter__` and `__exit__` raise and lower `_buffer_index`, which lives in `ConsoleThreadLocals`. Output is only written to the file when the index returns to 0. `capture`, `pager`, `Live.refresh`, `FileProxy.write`, `control()` and `print()` all depend on this. Bypassing it, or changing `_write_buffer` and `_render_buffer`, affects recording, the Windows legacy renderer, Jupyter display and the 32KB split-write workaround on Windows.
