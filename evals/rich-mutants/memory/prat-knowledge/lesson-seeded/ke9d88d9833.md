tests (part 2) is the second half of Rich's pytest suite (test_panel.py through test_windows_renderer.py). Each file covers one rich module: renderables (Panel, Table, Tree, Rule, Syntax, Text, Spinner, Status, Styled, Screen), data and formatting (Style, Segment, Theme, pretty, repr), progress and prompt, traceback, and internal helpers (`_pick`, `_ratio`, `_loop`, `_stack`, `_unicode_data`). The Windows-only console backend `_win32_console` and `_windows_renderer` also have tests here. Most tests build a `Console` that writes to `io.StringIO` or uses `console.capture()`. They then compare the output with exact expected strings, often including raw ANSI escape codes. Tests in this module depend on the exact output of `rich/console.py`, `rich/segment.py`, `rich/style.py` and `rich/text.py`, so changes to those files show up as many golden-string failures here.
