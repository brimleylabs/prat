box.rst defines `appendix_box`, with an underscore. colors.rst defines `appendix-colors`, with a hyphen. They are referenced from panel.rst, tables.rst, console.rst and style.rst. Renaming or normalising a label breaks those `:ref:` links, so grep for the label first and update every use together.
