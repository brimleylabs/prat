Renderables look styles up through `console.get_style(name, default=...)`, which uses the theme stack and falls back to `Style.parse`. `DEFAULT_STYLES` holds all the dotted names used by markdown, logging, repr, json, traceback, progress, layout and others. When adding a renderable that uses a new `foo.bar` style name, add the default to this dict. `python -m rich.default_styles` prints the table (use `--html` for an HTML export).
