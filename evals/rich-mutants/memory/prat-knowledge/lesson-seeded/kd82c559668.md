`render(renderable, no_wrap=False)` prints at width 100 with truecolor to a StringIO and normalises hyperlink ids via `replace_link_ids`, so `id=...;path` becomes `id=0;foo`. Import it with `from .render import render`, as test_bar, test_block_bar and test_emoji do. Some files (test_card, test_log, test_markdown*) copy the regex locally instead of importing it.
