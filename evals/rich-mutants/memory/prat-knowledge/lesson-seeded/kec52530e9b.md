`ratio_resolve` can return sizes summing to more than `total` when minimums conflict, and the caller (layout) clips the overflow. `ratio_distribute` asserts that the ratios sum to more than 0. `_wrap.divide_line` works in terminal cells via `cell_len` and `chop_cells`, and its `fold` flag chooses between folding and cropping over-long words. Offsets it returns are string indices, not cell offsets. `_loop.loop_first`, `loop_last` and `loop_first_last` return nothing for empty input.
