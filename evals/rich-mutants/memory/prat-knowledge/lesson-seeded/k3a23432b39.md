The templates use `questions`, `question.title`, `question.slug`, `question.body`, and `faq_url`. The links in `suggest.md` are built as `{{ faq_url }}#{{ question.slug }}`. They only work if they match the `<a name>` anchors that `FAQ.md` generates. Renaming a variable or changing the anchor format in one file breaks the links from the other.
