Each unicodeX-Y-Z.py file is produced from wcwidth tables as a `CellTable(version, widths, frozenset(narrow_to_wide))`. The widths table is sorted (start, end, width) tuples, where width 2 is wide East Asian and 0 is zero width. The narrow_to_wide set comes from wcwidth's VS16_NARROW_TO_WIDE for version 9.0.0 and is the same in every version file. Each file starts with an 'Auto generated by tools/make_width_tables.py' header.
