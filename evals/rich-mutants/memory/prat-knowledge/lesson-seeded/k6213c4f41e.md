`load()` parses the version to a 3-int tuple, padding missing parts with 0. If the exact version is not in `VERSION_SET`, it uses `bisect_left` on `VERSION_ORDER` and takes the previous entry. Anything below 4.1.0 gets the first version, and anything above the maximum gets the last. Malformed strings fall back to latest and no error is raised, which `test_load_version_invalid` checks.
